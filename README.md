# LuaVG

Camada de abstração em cima do SVG, as chamadas de função da biblioteca vão ter como resultado 
a escrita de códigos SVG.


Haverá um live mode onde cada chamada de função atualizar imediatamente um arquivo, essas alterações podem ser visualizadas com qualquer visualizador de imagens que automaticamente detecte as mudanças

As alterações realizadas podem ser armazenadas em outro arquivo para que seja possível realizar operações de undo e redo.
